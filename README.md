# Adventure Ball

## Synopsis

*Adventure Ball is a physics-based, 3d platformer, where you control a ball that can't stop bouncing! Once you run out of momentum, you lose. Bounce off floors and trampolines to keep moving to the end.*

Controls

* Move

  * WASD or Arrows to move horizontally
  * R to reset
